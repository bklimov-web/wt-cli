# wt — план переезда на Go

Контекст решений зафиксирован в grilling-сессии (2026-09-11). Кратко: текущий
`wt` — рабочий bash-черновик для создания git worktree (`new`, `ls`, `rm`,
`open`, `path`). Переписываем на Go, потому что bash тяжело читать и
дополнять, а Go даёт единый бинарник без рантайма — полезно и сейчас, и если
дойдём до публичного релиза.

Работаем фазами. Фаза A — личный инструмент. Фаза B — публичный релиз,
начинается только если A прижилась на практике.

---

## Фаза A — личный инструмент на Go

Цель: `wt`, которым реально пользуюсь каждый день на рабочем проекте, с
полным паритетом фич + начальные улучшения. Bash-версия выводится из
использования сразу, без параллельного проживания.

## Отклонённые/отложенные идеи

- **Полный отказ от скрипта в пользу ad hoc агента на каждый вызов** —
  отклонено: операция частая и рутинная, хочется секунд, а не ожидания
  агента.
- **Поддержка редакторов кроме VS Code** — отложено до фазы B, но команда
  редактора уже конфигурируема с фазы A, так что добавить будет дёшево.
- **Переименование бинарника ради избежания коллизий** — отклонено, `wt`
  остаётся; конфликт решается на стороне пользователя (см. README в фазе B).
